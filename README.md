# Urban Flow

## Sprint 1

## Objetivo
Analizar y depurar los datos históricos de multas por exceso
de velocidad del sistema legado de la localidad de Vaalserberg,
Bélgica, para obtener información consistente y relevante.

## Introducción y Contexto
La localidad de Vaalserberg opera en zona fronteriza con
Países Bajos y Alemania. Su sistema de radares urbanos genera
registros con errores de formato y datos faltantes provenientes
de sistemas heredados. Este sprint tiene como objetivo limpiar,
normalizar y analizar dichos registros para su futura migración
al nuevo sistema sin inconsistencias.
